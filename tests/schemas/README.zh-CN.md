# SARIF schema 来源说明

**简体中文** | [English](README.md) | [返回首页](../../README.md)

`sarif-2.1.0.json` 是未修改的 OASIS SARIF 2.1.0 JSON schema，于 2026-10-02 下载自[官方仓库](https://github.com/oasis-tcs/sarif-spec/blob/main/sarif-2.1/schema/sarif-schema-2.1.0.json)。

该文件保留在仓库中，使报告格式测试无需联网。schema 中原有的 OASIS 版权元数据得到保留；它不属于 FontGuard 自有内容。
